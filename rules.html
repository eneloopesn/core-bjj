競賽規程

115年基隆市長樂國小家長會長盃柔術錦標賽

一、比賽宗旨

為推廣基隆柔術運動，培養學童規律運動習慣，促進身心健康發展，透過柔術競技活動，培養學童尊重、紀律、勇氣、自信及運動家精神，並藉由比賽增進學校社團、民間訓練單位之間的交流與友誼，提供學童展現平日訓練成果的舞台。

二、指導單位

基隆市長樂國民小學

三、主辦單位

基隆市長樂國小家長會、基隆市柔術協會

四、承辦單位

基隆市長樂國民小學巴西柔術社、基隆市柔術協會

五、協辦單位

基隆市長樂國民小學、Jabari Jiu-Jitsu（伽戰柔術）

六、贊助單位

社團法人基隆市牙醫師公會、基隆市私立安馨居家長照機構

七、比賽日期

中華民國115年12月13日（星期日）

八、比賽地點

基隆市長樂國小 3 樓禮堂
地址：基隆市安樂區樂利三街30巷123號

九、報名方式及費用

  1. 報名方式：採線上報名，依主辦單位公告之報名表單填寫資料。
  2. 報名資格：凡符合各組年齡及競賽資格之白帶學童，均可報名參加。
  3. 報名費用：每位選手新臺幣500元。
  4. 報名截止日期：115年11月26日（星期四晚上23:59）。
  5. 報名完成後，如因個人因素無法參賽，恕不退費。

十、參賽資格及年齡分組

  1. 參賽資格限長樂國小巴西柔術社學生及 Jabari Jiu-Jitsu（伽戰柔術）道館學生。
  2. 參賽選手須具備基本柔術訓練經驗及相關運動能力，並了解基本競賽規則。
  3. 未滿18歲之選手，報名時須由法定代理人簽署參賽同意書及個人資料使用同意書。
  4. 年齡分組以比賽當日年齡為計算基準，分組如下：
    • 兒童組：未滿8歲。〈2018年12月13日（不含當天）以後出生〉
    • 少年組：8歲至10歲。〈2015年12月13日（不含當天）以後出生，2018年12月13日（含當天）以前出生〉
    • 青少年組：11歲至12歲。〈2013年12月13日（不含當天）以後出生，2015年12月13日（含當天）以前出生〉
    • 青年組：13歲至未滿16歲。〈2010年12月13日（不含當天）以後出生，2013年12月13日（含當天）以前出生〉
  5. 各組得依實際報名人數、年齡、體重及訓練程度進行分組調整。
  6. 主辦單位得視報名情形，合併或調整組別，以維護競賽公平性及選手安全。

十二、競賽辦法

  1. 競賽規則以台灣柔術總會（TJJF）相關柔術競賽規則為參考，並依兒童及青少年選手之年齡特性，訂定適用之競賽規範。
  2. 競賽分組依年齡、性別、體重及實際報名人數安排。
  3. 體重分級由主辦單位依報名情況公告，必要時得調整級別。
  4. 比賽採淘汰制或循環賽制，依各組報名人數決定。
  5. 比賽時間及計分方式由裁判長依各組年齡及競賽規則統一公告。
  6. 競賽過程中，選手應尊重裁判判決，不得有辱罵、挑釁或其他違反運動精神之行為。
  7. 有關比賽規則及未盡事宜，由裁判長及競賽組依現場狀況裁定。

十三、選手注意事項

  1. 選手應於規定時間內完成報到、量級確認及檢錄，逾時未到者視同放棄參賽。
  2. 選手須穿著符合競賽規定之柔術道服。
  3. 選手應修剪指甲，不得配戴手錶、飾品或其他可能造成自身及對手受傷之物品。
  4. 選手須自行評估身體狀況，如有受傷、疾病或其他不適合參賽之情形，應主動告知主辦單位及裁判。
  5. 比賽期間應遵守裁判指示，禁止使用不符合該年齡組規定之危險技術。
  6. 選手如有故意傷害對手、違反競賽規則或其他危害安全之行為，裁判得視情節予以警告、扣分或取消資格。

十四、獎勵辦法

  1. 各組依參賽人數及競賽成績，頒發第一名、第二名及第三名獎牌（2名）。
  2. 各組獲獎選手頒發獎牌，以資鼓勵。

十五、競賽醫療及安全措施

  1. 比賽現場應安排基本醫療及緊急應變措施。
  2. 競賽期間如選手發生受傷情形，裁判得立即停止比賽，並由現場醫療人員進行評估。
  3. 如經評估不適合繼續比賽，為保障選手安全，得停止其後續競賽資格。
  4. 主辦單位應確保競賽場地、軟墊及相關器材符合安全需求。

十六、其他事項

  1. 參賽選手及家長應遵守大會相關規定，共同維護良好競賽秩序。
  2. 參賽選手之個人資料及活動照片，依報名時所簽署之個人資料及影像使用同意書辦理。
  3. 如遇天災、不可抗力因素或其他特殊情況，主辦單位得調整、延期或取消比賽，並另行公告。
  4. 本規程如有未盡事宜，得由主辦單位修正補充，並以最新公告為準。
