# Jabari 巴西柔術館內賽報名網站

靜態網站（GitHub Pages）＋ Google Apps Script 線上資料庫與寄信。

## 功能

- 館內賽介紹與單場報名費
- 線上報名（成人組／兒童組）
- 兒童組年齡區間、體重級別
- 修改報名資料
- 已報名選手列表
- 電子信箱選填；有填才寄確認／更新通知信

## 啟用

1. 依 [`backend/README.md`](backend/README.md) 部署 Apps Script，並填入 `js/config.js`
2. 推上 GitHub，開啟 Pages（`main` / root）

網站：`https://<帳號>.github.io/<repo>/`
